## Как проверить самому

1. `pravo.by` → Национальный реестр → поиск по номеру постановления (надёжнее, чем по шифру).
2. `stn.by/standartisation/splist` — реестр СН и СП с постановлениями.
3. `minskgsn.by` — перечень действующих СН с датами введения.
4. `mchs.gov.by` — перечень ТНПА в области пожарной безопасности (обновляется ежемесячно).
