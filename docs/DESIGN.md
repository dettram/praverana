# Дизайн и гейты

## Бренд

- Название: **Праверана.by** («проверено»), домен в имени.
- Знак: ромб (основа рушникового орнамента) с галочкой; золотая обводка на тёмном.
- Палитра из государственной символики: красный `#C8102E`, зелёный `#23694A`,
  золотой `#8A5F14` (текст) / `#A97C22` (графика), бумага `#FAF9F5`, тушь `#15181A`.
- Герб не воспроизводится: использование регулируется законодательством, в подвале есть оговорка.
- Шрифты: Onest (variable) + JetBrains Mono, оба OFL, локально (`@font-face`), без Google Fonts.

## Страницы

- `/` — лендинг: герой с живым скриншотом, пять проверок, отчёт, разметка, история, закрытие.
- `/app` — инструмент: папка → замечания → DOCX/PDF/ZIP с разметкой.

## Гейты (design-taste-frontend)

| Проверка | Результат |
|---|---|
| copy-lint | 0 FAIL, 2 WARN (7 тире; полоса цифр из истории) |
| consistency 1440×900 | 0 FAIL, 6 WARN, 7 экранов |
| consistency 390×844 | 0 FAIL, 3 WARN |
| обход 320×640 | 0 FAIL |
| gate.mjs | **GATE: PASS**, 8 WARN |

Waiver'ы (`.taste-skill/waivers.json`): `hero-lines` и `hero-maxchars` — чекер подставляет 45 знаков
вместо фактических 26 и считает строки для чужого заголовка.

Незакрытые WARN: `copy-headline` (h1 не называет категорию прямо), `copy-actions` (CTA в шапке
дублирует кнопку героя), `section-gaps` (зазор герой→проверки больше остальных), `nav-current`,
`skip-link` (контраст), `photo-weight` (скриншоты 120–200 КБ), `empty-visual` (картинка в истории
почти монохромная), `moment-none` (момент есть, эвристика не распознала).
