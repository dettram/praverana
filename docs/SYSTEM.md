## 5. Пять приоритетных правок

1. **Кит — шаг поставки.** `setup-kit.ps1` и проверка `assets/system.css` перед деплоем
   (`landing.html:19`, `docs/LANDING.md:7–14`). В чистом клоне лендинг без стилей, переменные
   `--t-small`, `--s-4`, `--r-lg` не объявлены.
2. **Один `tokens.css`.** Сейчас два несвязанных набора: `index.html:9–21` и `landing.html:26–37`;
   `--accent` = ink, `--p-accent` = золото — одно имя роли, два значения.
3. **Один `.btn--primary/.btn--secondary`.** Один класс — два размера и два hover
   (`index.html:58–69, 74`; `:61–64` ↔ `landing.html:105`).
4. **Золото текстом — `#8a5f14`** (`index.html:13, 40, 131`); починить `font:13px/1.4 inherit`
   (`:117`) — невалидный shorthand, поле поиска не получает Onest; решить судьбу синего (`:14`).
5. **Шкала.** 14 кеглей и радиусы 9/10 px в `index.html` свести к шкале; заголовки — одна пара
   (`index.html:46` ↔ `landing.html:34`).
