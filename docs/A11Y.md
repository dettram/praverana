# A11Y: доступность лендинга и /app

Аудит по коду, без живого прогона. Контраст посчитан по hex из CSS. Порог — WCAG AA.

## 1. Карта и скоуп

- FastAPI (`app/server.py`) отдаёт `app/ui/index.html` на `/app` и `app/ui/landing.html` на `/`;
  статика — `/assets` (`server.py:32`).
- Проверены `app/ui/index.html` (CSS и JS inline), `app/ui/landing.html`, ответы API
  (`server.py:54, 82–154`).
- Канон: `docs/BRIEF.md` (AA, клавиатура, reduced motion).

## 3. Состояния

| Экран | Пусто | Загрузка | Ошибка | Нет прав | Плотно |
|---|---|---|---|---|---|
| `/app` | нет подсказки (`#intro` скрыт) | live-регион есть; фокус сбрасывается | не объявляется; сырой текст; вечный poll на 404 | `PermissionError` в сыром виде | таблица ломает 320px |
| `/` | статичный | — | — | — | без ассетов кита; подписи скрыты на телефоне |

Долгий прогон: текст не меняется, времени и отмены нет. Предложение: через 30 с писать
«Прошло 30 с. Большие папки занимают несколько минут».

Хорошо: `lang="ru"`; `aria-live` на статусе; `aria-pressed` и `role="group"` у фильтров;
уровни подписаны текстом, не только цветом; у всех картинок лендинга есть `alt`; ошибка PDF
предлагает DOCX.

## 4. Не проверено

- Живьём: сервер не поднимался, Tab-обход, 200%/320px, скринридер.
- Лендинг без ассетов: фокус, reduced motion, nav-toggle, skip-link, вёрстка 320px.
- Пустая папка (0 документов): отдельного сообщения в коде нет — риск отчёта с оценкой без пояснения.
- Возврат фокуса после системного диалога выбора папки.

## 5. Пять приоритетных правок

Перед ними — ассеты лендинга (см. первый блокер).

1. Ошибка и итог — в объявляемый регион; не зависать на 404.
2. Не отключать кнопку во время прогона: `aria-disabled`; при пустом пути — `aria-invalid` и фокус.
3. Понятные тексты ошибок на сервере и в JS.
4. Таблица в скролл-обёртке с `scope` у заголовков.
5. Контраст `#8a5f14` и границ `#8a8f94`; показать «Что проверяется» до первого запуска.
