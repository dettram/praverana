# Архитектура

## Слои

```
app/engine.py     обход папки, извлечение текста, проверки, свёртка находок
app/report.py     DOCX (Times New Roman, А4) + PDF через Word COM
app/markdoc.py    копии DOCX: комментарии Word + подсветка
app/history.py    сохранение прогонов и сравнение «стало лучше / хуже»
app/server.py     FastAPI: /api/audit, /api/upload, /api/report/{job}.docx|pdf, /api/marked.zip
app/ui/           лендинг (/), инструмент (/app)
scripts/          корпус: индексация, поиск, реестр, проверки ссылок, ПОС/ППР, СГП
```

## Проверки движка

| Категория | Что делает | Источник |
|---|---|---|
| нормы | извлекает шифры, сверяет статус | `02-Реестр.csv` + `norm_check.classify` |
| цитаты | пары «шифр — пункт» в пределах 80 знаков строки, проверяет наличие пункта | индекс `.stroy-audit/index.sqlite` |
| комплект | ищет ПЗ, АР, КР/КЖ/КМ, ИОС, ПОС, ППР, сметы по именам файлов | эвристика |
| ПОС/ППР | состав по приложениям Г и В СН 1.03.04-2020 | `data/pos-ppr.json` |
| заглушки | «ХХХ», «___», «заполнить»; «по проекту» — отдельно, как инфо | регулярные выражения |

Находки по нормам **свёрнуты по шифру**: один шифр — одна строка со списком файлов и числом
вхождений. DOCX и PDF одного документа считаются одним источником (ключ — имя без расширения).

## Оценка

`10 − min(6, 1·ошибки) − min(3, 0.2·предупреждения) − min(1, 0.05·инфо)`.
Ниже 5 — «существенные дефекты», 5–8 — «требуются исправления», выше 8 — «пригодно к проверке».

## История

`~/.stroy-audit/audit-runs/<время>-<хеш папки>.json`. Сравнение по смыслу замечания:
(категория, норма, текст без счётчиков). Если состав выборки менялся, сравнение помечается
условным — интерфейс и отчёт пишут это прямо.

## Разметка

`python-docx` 1.2 (`Document.add_comment`), деление run по границам найденного текста,
подсветка `WD_COLOR_INDEX`. До 3 вхождений на шифр и до 80 комментариев на файл — иначе Word
открывается слишком долго. PDF не размечается.

## Зависимости

Python 3.11+, `uv`; для PDF — установленный Microsoft Word (экспорт через COM).
Для интерфейса — FastAPI/uvicorn, `python-docx`, `pypdf`, `python-multipart`.
